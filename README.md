# ระบบจองห้องประชุมออนไลน์ (Smart Meeting Room Booking System)

เว็บแอปพลิเคชันระบบจองห้องประชุมออนไลน์แบบ Standalone พร้อมใช้งานได้ทันที **100% โดยไม่ต้องเชื่อมต่อฐานข้อมูลภายนอก (Supabase) และไม่ต้องล็อกอิน** รองรับภาษาไทยสมบูรณ์แบบ ออกแบบ Responsive สวยงามและใช้งานง่ายบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

---

## 🌟 ฟีเจอร์เด่นของระบบ

### 1. เข้าใช้งานและจองห้องได้ทันที (Zero Setup & No Login)
- **ไม่ต้องสมัครสมาชิก/ไม่ต้องล็อกอิน:** ผู้ใช้ทั่วไปสามารถเปิดหน้าเว็บ เลือกห้อง และกรอกข้อมูลจองได้ทันที
- **สลับโหมดผู้ดูแล (Admin Toggle):** บน Navbar มีปุ่มสลับเป็น **"โหมดผู้ดูแล (Admin)"** ในคลิกเดียว เพื่อเข้าถึงแดชบอร์ด จัดการห้อง จัดการการจอง และดาวน์โหลดรายงาน CSV
- **จดจำข้อมูลผู้จอง:** ระบบจดจำชื่อและแผนกของผู้ใช้งานในเบราว์เซอร์อัตโนมัติ ไม่ต้องกรอกซ้ำในครั้งต่อไป

### 2. ระบบป้องกันการจองเวลาทับซ้อน (Anti-Overlap Engine)
- **Real-time Pre-check:** ตรวจสอบช่วงเวลาทันทีเมื่อผู้ใช้เปลี่ยนวันหรือเวลา หากห้องนั้นมีผู้อื่นจองไว้แล้ว ระบบจะแสดงแถบเตือนสีส้มพร้อมบอกชื่อรายการที่ชนกัน และปิดปุ่มยืนยันทันที ป้องกันการจองซ้อน 100%
- **เวลาและเขตเวลา:** ใช้เขตเวลาประเทศไทย `Asia/Bangkok (UTC+7)` แสดงวันเดือนปีเป็นภาษาไทย (พ.ศ.) ชัดเจน

### 3. ปฏิทินตารางการจอง (Calendar Views)
- ดูตารางการประชุมได้ 3 รูปแบบ: **รายวัน (Day)**, **รายสัปดาห์ (Week)**, และ **รายเดือน (Month)**
- มีตัวกรองแยกดูเฉพาะห้องประชุมที่สนใจได้

### 4. หน้ารายการจองและการแจ้งเตือน (My Bookings & In-App Notification)
- ดูรายการจองที่กำลังจะมาถึง (Upcoming) และประวัติที่ผ่านมา (Past)
- ขอยกเลิกการจองได้เอง พร้อม Modal ยืนยันก่อนยกเลิก ป้องกันการกดพลาด
- ศูนย์แจ้งเตือนในแอป (Notification Center) แจ้งเตือนเมื่อจองสำเร็จ หรือเมื่อมีการยกเลิก

### 5. แดชบอร์ดและรายงานสำหรับผู้ดูแล (Admin Features)
- **แดชบอร์ดภาพรวม:** แสดงจำนวนห้องทั้งหมด, ห้องที่กำลังใช้งานอยู่ ณ ขณะนี้แบบเรียลไทม์, จำนวนการจองวันนี้, และสถิติห้องยอดนิยม
- **จัดการห้องประชุม:** เพิ่มห้องใหม่, แก้ไขข้อมูลห้อง (ชื่อ, ความจุ, อุปกรณ์, รูปภาพ), และเปิด/ปิดให้บริการห้อง
- **จัดการรายการจอง:** แอดมินสามารถดูและกดยกเลิกการจองที่ไม่เหมาะสมได้
- **รายงานสรุป & ส่งออก CSV:** กรองตามช่วงวันที่ ห้อง และสถานะ พร้อมปุ่ม **ส่งออกเป็น CSV** ที่มีรหัส UTF-8 BOM เปิดใน Microsoft Excel แล้วภาษาไทยไม่เป็นภาษาต่างดาว

## 🚀 วิธีเปิดใช้งานระบบบนเครื่อง

1. เปิด Terminal หรือ PowerShell ที่โฟลเดอร์โปรเจกต์
2. รันคำสั่งเปิดเซิร์ฟเวอร์:
   ```bash
   npm run dev
   ```
   หรือสำหรับโหมด Production:
   ```bash
   npm run build
   npm run start
   ```
3. เปิดเว็บเบราว์เซอร์ไปที่: **`http://localhost:3000`**

## 📁 โครงสร้างโปรเจกต์สำคัญ
- `src/context/BookingContext.tsx` - ระบบจัดเก็บข้อมูลกลาง (State & Local Storage Manager พร้อม Seed Data และ Anti-Overlap Engine)
- `src/app/page.tsx` - หน้ารายการห้องประชุม ค้นหา และกรองตามความจุ/อุปกรณ์
- `src/app/book/page.tsx` - แบบฟอร์มจองห้องประชุมและระบบตรวจเวลาชนแบบ Real-time
- `src/app/calendar/page.tsx` - ปฏิทินรายวัน / รายสัปดาห์ / รายเดือน
- `src/app/my-bookings/page.tsx` - รายการจองและศูนย์แจ้งเตือน
- `src/app/admin/dashboard/page.tsx` - แดชบอร์ดสถิติผู้ดูแลระบบ
- `src/app/admin/rooms/page.tsx` - จัดการห้องประชุม เพิ่ม/แก้ไข/เปิด-ปิด
- `src/app/admin/bookings/page.tsx` - ตรวจสอบและยกเลิกรายการจอง
- `src/app/admin/reports/page.tsx` - รายงานสรุปและส่งออก CSV
- `src/components/Navbar.tsx` - เมนูนำทางพร้อมปุ่มสลับโหมด Admin
