เว็บแอปพลิเคชันระบบจองห้องประชุมออนไลน์แบบ Standalone พัฒนาด้วย Next.js, TypeScript และ Tailwind CSS ออกแบบตามหลัก User Experience (UX/UI) รองรับการใช้งานภาษาไทย 100% ใช้งานได้ครอบคลุมทั้งบนสมาร์ทโฟน แท็บเล็ต และคอมพิวเตอร์

## 🌟 ฟังก์ชันการทำงานหลักของระบบ (Features)

### 1. ระบบเลือกและดูข้อมูลห้องประชุม (Room Browsing)
- แสดงรายการห้องประชุมทั้งหมด พร้อมภาพตัวอย่าง ขนาดความจุที่นั่ง สถานที่/ชั้น และสิ่งอำนวยความสะดวก
- มีระบบค้นหาตามชื่อห้อง และตัวกรองตามขนาดความจุที่นั่ง (เล็ก / กลาง / ใหญ่) และอุปกรณ์ในห้อง
- แสดงป้ายสถานะความพร้อมใช้งานของห้องแบบเรียลไทม์

### 2. ระบบการจองห้องและการป้องกันเวลาชนกัน (Anti-Overlap Booking Engine)
- ผู้ใช้งานสามารถจองห้องประชุมได้ทันทีโดยไม่ต้องผ่านขั้นตอนการสมัครสมาชิก
- ระบุหัวข้อการประชุม, ผู้จอง, แผนก/ฝ่าย, จำนวนคน, และช่วงเวลา (เขตเวลาประเทศไทย `Asia/Bangkok (UTC+7)`)
- **ระบบป้องกันการจองเวลาทับซ้อน (Real-time Pre-check):** เมื่อเลือกวันและเวลา ระบบจะตรวจสอบกับฐานข้อมูลทันที หากมีผู้อื่นจองช่วงเวลานั้นไว้แล้ว จะแสดงแถบแจ้งเตือนสีส้มพร้อมบอกชื่อรายการที่ชน และปิดปุ่มยืนยัน ป้องกันปัญหาการจองเวลาซ้อน 100%

### 3. ปฏิทินตารางการจองห้องประชุม (Interactive Calendar)
- แสดงตารางการประชุมได้ 3 รูปแบบ:
  - **มุมมองรายวัน (Day View):** ดูตารางเวลาละเอียดตลอดทั้งวัน
  - **มุมมองรายสัปดาห์ (Week View):** สรุปภาพรวมการประชุมของสัปดาห์นั้น
  - **มุมมองรายเดือน (Month View):** ดูภาพรวมปฏิทินตลอดทั้งเดือน
- มีตัวกรองเพื่อเลือกดูเฉพาะห้องประชุมที่ต้องการ

### 4. หน้ารายการจองของฉัน & ระบบแจ้งเตือน (My Bookings & In-App Notification)
- แบ่งหมวดหมู่การจอง: **"กำลังจะมาถึง (Upcoming)"** และ **"ประวัติการจองเดิม (Past)"**
- ผู้ใช้งานสามารถยกเลิกการจองได้ด้วยตนเอง พร้อมหน้าต่าง Modal ยืนยันก่อนยกเลิก ป้องกันการกดพลาด
- ศูนย์แจ้งเตือนในระบบ (In-App Notification) แจ้งเตือนเมื่อจองห้องสำเร็จหรือเมื่อมีการยกเลิกรายการ

### 5. แดชบอร์ดและเครื่องมือผู้ดูแลระบบ (Admin Portal)
- **สลับโหมดผู้ดูแลในคลิกเดียว:** มีปุ่ม Toggle **"โหมดผู้ดูแล (Admin)"** บนแถบเมนูด้านบน เพื่อเข้าถึงระบบบริหารจัดการ
- **แดชบอร์ดภาพรวม:** แสดงสถิติจำนวนห้องทั้งหมด, ห้องที่กำลังใช้งานอยู่ ณ ขณะนี้แบบเรียลไทม์, รายการจองวันนี้, และสถิติห้องที่ถูกใช้งานบ่อยที่สุด
- **จัดการห้องประชุม:** ผู้ดูแลสามารถเพิ่มห้องประชุมใหม่, แก้ไขข้อมูลห้อง, และเปิด/ปิดการให้บริการของห้องได้
- **จัดการรายการจอง:** ตรวจสอบและยกเลิกรายการจองทั้งหมดของทุกคนในองค์กร
- **รายงานสรุป & ส่งออก CSV:** กรองรายงานตามช่วงวันที่ ห้อง และสถานะ พร้อมปุ่ม **"ส่งออกเป็น CSV"** โดยมีรหัส UTF-8 BOM รองรับการเปิดใช้งานด้วย Microsoft Excel ภาษาไทยไม่เป็นภาษาต่างดาว

## 🚀 วิธีการเปิดใช้งานระบบ (สำหรับอาจารย์ / ผู้ตรวจงาน)

### วิธีที่ 1: รันแบบคลิกเดียวบน Windows (แนะนำ ง่ายที่สุด)
1. ดาวน์โหลดไฟล์โปรเจกต์จาก GitHub หรือแตกไฟล์ ZIP
2. ดับเบิลคลิกที่ไฟล์ **`start-app.bat`**
3. ระบบจะเปิดหน้าเว็บเบราว์เซอร์ไปที่ **`http://localhost:3000`** ให้โดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / Command Prompt
```bash
# 1. Clone repository
git clone https://github.com/taratch/aye.git
cd aye

# 2. ติดตั้ง Dependencies
npm install

# 3. รันโปรเจกต์
npm run dev
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`
